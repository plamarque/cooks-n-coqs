# Douze keyframes pour les etats actifs du Chef

## Intent

**Problem:** Les huit poses des cinq sequences actives du spike restaient visuellement trop sacadees pour juger le rythme du Chef.

**Approach:** Remplacer leurs planches 4 x 2 par des planches 4 x 3, faire jouer les douze poses sur les durees existantes et conserver le Repos, volontairement tres calme, tel quel. Cette iteration reste une comparaison de storyboards aplatis, non le format de production.
